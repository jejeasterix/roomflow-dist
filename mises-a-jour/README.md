# Mises à jour de RoomFlow

Ce que change chaque version de l'application Windows, la plus récente en tête.
Votre version s'affiche au pied du menu de votre compte (clic sur votre avatar).

La mise à jour est automatique : RoomFlow la télécharge au démarrage et vous propose de
redémarrer quand elle est prête. Les installateurs sont dans les
[releases](https://github.com/jejeasterix/roomflow-dist/releases).

| Version | Date | En bref |
|---|---|---|
| [v1.0.50](v1.0.50.md) | 24/10/2026 | Studio : plusieurs câbles par port, styles des tags, câblage AUDIO PHOENIX ↔ HP ; Communauté réservée à Cloud ; types de ports Officiels (Mini BNC) pris en compte partout ; carnet de câblage complet |
| [v1.0.49](v1.0.49.md) | 18/10/2026 | Studio : budget PoE par switch, dessinateur dans le cartouche ; signaler un problème ; mots de passe du Tableau IP masqués ; catalogue chiffré ; démarrage plus rapide |
| [v1.0.48](v1.0.48.md) | 14/10/2026 | Studio : puissance, dissipation et bilan électrique dans la nomenclature et ses exports ; export des couleurs des nodes |
| [v1.0.47](v1.0.47.md) | 13/10/2026 | Studio : le panneau « Où est mon schéma » dit juste ; la sélection des nodes ne se bloque plus |
