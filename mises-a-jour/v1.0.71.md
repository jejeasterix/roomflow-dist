## Corrections

### Les câbles virtuels apparaissent dans le schéma unifilaire

Dans Studio, le schéma unifilaire ignorait les câbles virtuels. Il les transforme maintenant comme les câbles classiques : même catégorie, même couleur, même sens.
Un câble virtuel reste virtuel : il se montre par ses deux étiquettes-flèches, sans trait. Un câble réseau ou USB garde sa double flèche.
La légende du schéma compte aussi les catégories de ces câbles.
Une variante unifilaire déjà créée ne change pas : créez-en une nouvelle pour voir vos câbles virtuels.
