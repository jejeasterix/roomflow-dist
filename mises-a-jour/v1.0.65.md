## Nouveautés

### Studio : image glissée, collée ou importée

Glisser une image sur le plan, la coller (Ctrl+V) ou l'importer par Insertion › Importer Image pose de nouveau un objet image. Le fond blanc est détouré et la désignation vient du nom du fichier.

### Studio : image de référence

Affichage › Importer Image pose l'image de référence. Elle se place derrière les pictogrammes.

## Corrections

### Studio : images illisibles

Quand vous déposez des images illisibles, le message indique maintenant ce qui s'est vraiment passé.

### Studio : plusieurs plans ouverts

Le Studio est plus léger quand plusieurs plans sont ouverts en même temps.
