## Nouveautés

### Sans accès Cloud, Studio travaille en local et le dit

Quand votre compte n'a plus d'accès Cloud, Studio passe seul en travail local, sur ce poste. Il n'envoie plus rien dans votre espace, et un bandeau vous le dit une fois.
Vos données Cloud sont gardées. Pour garder un schéma de votre espace, utilisez « Enregistrer sous… » : Ctrl+S vous y conduit. Si un fichier `.rflow` est ouvert, Ctrl+S l'enregistre sur votre poste.
Le bouton « Voir ma formule » du bandeau ouvre votre page « Ma formule », dans RoomFlow sur le web. Dès que votre accès Cloud revient, sans redémarrer, Studio renvoie dans votre espace le travail fait entre-temps.
