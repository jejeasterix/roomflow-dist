## Corrections

### Studio : image glissée dans le plan

Une image glissée dans le plan est maintenant posée comme une image de l'outil Image. Elle se place derrière les pictogrammes, qui restent visibles et cliquables.

### Studio : rotation d'un pictogramme

Après avoir tourné un pictogramme par sa poignée, l'outil revient à la sélection. Vous pouvez enchaîner sans changer d'outil.
