## Nouveautés

### Présentation des catalogues

À la première ouverture de Studio, une fenêtre présente les 4 catalogues de produits : Officiel, Entreprise, Communauté et Personnel.
Un second écran explique comment une fiche de produit est notée.
Pour la revoir : menu Affichage › « Présentation des catalogues ».

### Page Utilisateurs pour le super admin

Le menu du compte de l'app propose « Utilisateurs », juste après « Mon entreprise ».
Cette entrée ouvre la page Utilisateurs de l'administration. Seul le super admin la voit.
